What is Round Robin (RR)?

Round Robin is a preemptive scheduling algorithm where each process (customer query) is given a fixed time slice called the Time Quantum.

How Customer Service Scheduling Works:
  • Ready Queue: Queries wait in a FIFO queue for available agents.
  • Time Slice: The agent serves the query for at most Time Quantum units.
  • Preemption: If query requires more time, it is requeued at the tail of the ready queue.
  • Completion: If query finishes within the slice, it is marked Completed and removed.
  • Multi-Agent Order: Scheduling turns alternate cyclically among available service representatives.
Key Performance Formulas:
• Turnaround Time (TAT) = Completion Time − Arrival Time
• Waiting Time (WT) = Turnaround Time − Burst Time
